TASK: Build PiTSR — CPU-only temporal super-resolution + denoiser on raylib + rlgl

You are implementing PiTSR (π Temporal Super-Resolution) for our rendering engine.

PiTSR is entirely CPU. No compute shaders, no CUDA, no OpenCL, no fragment-shader blur chain that is the upscaler. raylib / rlgl / rglfw are for window, GL context, low-res scene capture, texture upload, present, input, and debug HUD — not for running the filter.

Do not call InitWindow / GLFW yourself if the engine already owns the window. Use raylib’s bundled GLFW (rglfw). Never create a second GLFW context.
0. Goal

Internal render (noisy and/or lower res, linear HDR) → stable, sharp, temporally coherent display-res HDR with motion, minimal ghosting, leftover film grain (not plastic blur). Then blit with raylib.

Call it PiTSR in UI, logs, and DESIGN.md. No “Helios”.

3.2 Formats

    Internal scene RT: prefer PIXELFORMAT_UNCOMPRESSED_R16G16B16A16 or R32G32B32A32 via rlgl if the GL driver supports it. If not, render HDR in RGBE / log-luma + chroma or linear u8 only as last resort (document the quality hit).

    MVs: RG16F or RG32F texture → CPU f16/f32 planes.
    Present: LDR UNCOMPRESSED_R8G8B8A8 after a CPU ACES/Reinhard if the window is 8-bit, or keep float texture if you can blit it.

4. Architecture (visual math = production TSR; execution = CPU wavefront)
text
Copy

ingest pack (raylib Image → SoA, pre-expose, demodulate, RGB→OKLab/YCoCg)
  → tile classify
  → MV dilate + reactive dilate
  → reproject + Catmull-Rom history
  → disocclusion / AABB / luma instability
  → BATF Kalman accumulate + moments
  → à-trous / SVGF (2–5 iters)
  → reconstruct to display (Lanczos-2 / EWA + jitter invert, depth-aware)
  → CAS luma + blue-noise grain
  → egress (SoA → present Image) + history commit

Fuse classify + dilate + reproject + Kalman into one tile pass (W2) so color/depth/MV/history stay in L2. À-trous iterations need halo → barrier per iter.
5. Math (implement, don’t stub)

    Jitter: Halton(2,3) then R2; invert at reconstruct. Apply to raylib camera projection before BeginMode3D.
    History: Catmull-Rom in OKLab/YCoCg; depth + normal reject.
    AABB clamp + luma instability (UE5 TSR-style) to grow AABB / process noise.
    BATF (novel):
    K = P⁻/(P⁻+R), μ += K(z-μ), P = (1-K)P⁻
    R = spatial variance + spp proxy; q grows with motion, disocclusion, roughness, hitT.
    SVGF moments: m1,m2, var = max(0, m2-m1²).
    Dual EMA: fast (anti-ghost) + slow (anti-flicker).
    Edge-avoiding à-trous: w_z, w_n, w_luma/sqrt(var), w_mat, w_hit. Holes 1,2,4,…
    SpectralBlend (novel): more temporal on low-frequency levels, less on high (keeps texture/grain).
    Demodulate irr = color/max(albedo,ε); skip emissive.
    Dual lobe (flag): diffuse vs specular histories; specular MVs; anisotropic kernel along reflected-dir × roughness.
    Disocclusion: dilated MV + bilateral infill + reset length.
    Fireflies: luma clamp μ + κσ.
    CAS luma-only in OKLab.
    Grain: Heitz blue-noise, amplitude ∝ sqrt(leftover var), stable if camera still.

Cite in comments (ideas, no illegal code dumps): SVGF 2017, A-SVGF 2018, Dammertz à-trous, Karis TAA, Yang TAA survey, UE5 TSR, FSR 2.2 algorithm writeups, NRD ReBLUR concepts, Lottes CAS, Kopf JBU, Heitz blue noise.
6. Memory layout (CPU — this is the job)

Bandwidth wins. No AoS RGB structs in hot loops.
6.1 Tiles

    Default 32×32 (kTile=32), halo kHalo = (1<<(iters-1)) + 2 (Catmull-Rom/AABB), rounded to SIMD width.
    Overlapped tiles: job reads tile+halo, writes interior only.
    Ingest fills clamp-to-edge halo so inner loops have zero bounds branches.

7. Scheduling (CPU + raylib main thread)
7.1 Threading

raylib/GL = main. PiTSR tiles = work-stealing pool, N = hardware_concurrency - reservedThreads (default reserve 1 for main).

Do not std::async per tile. Do not OpenMP unless already in-tree. No GL on workers.
text
Copy

POOL:  tile jobs

7.2 Wavefront
Wave	Work	Sync
W0	Ingest + tile classify	barrier
W1	MV dilate (or fuse into W2)	barrier if separate
W2	Reproject + AABB + BATF (fused)	barrier
W3i	À-trous iter i	barrier each iter
W4	Reconstruct + CAS + grain + FeedbackSPI	barrier
W5	History swap	cheap

BudgetGate: if timeBudgetMs hit after W2, skip remaining W3; history still valid.

TileClass: Sky | StableLowVar | OpaqueMotion | Disocclude | HighVar | Transparent | Emissive
Skip/cheap à-trous on Sky/Stable. Full path on Disocclude/HighVar. Short history on emissive/alpha.

Job size: 1 tile or strip of 2–4 tiles (~50–200 µs). Parallelism across tiles, never inside a 32×32.
7.3 SIMD

AVX2 8-wide along X; fp16 load via F16C; à-trous uses regular ±step loads, not gathers. Catmull-Rom may gather. Pad width so no scalar tail. cpuid once; function table Scalar | AVX2 | AVX512. No virtual calls in kernels.

2. Hard rules (break the soup)

    Never denoise/upscale in sRGB/LDR. Linear + pre-expose only.
    Demodulate if albedo exists: filter irr = color / max(albedo, 0.02), remodulate after. Protect emissive.
    Frequency split: low frequencies may use long history; high frequencies must not.
    Spatial filter is allowed to leave noise. Stop when var hits a floor, do not drive it to 0.
    Grain is last (after reconstruct + CAS), using pre-spatial leftover energy, not post-spatial var≈0.
    History color resample: Catmull-Rom (or bicubic); display reconstruct: Lanczos-2, not bilinear.
    Camera must be jittered every frame. If jitter is 0, sharpness cannot be recovered.

4. Math patches (implement exactly)
4.1 Jitter invert (if missing, this alone causes blur)

Projection jitter in pixels: j = Halton/R2 ∈ (-0.5, 0.5).

Reconstruct at display pixel p using kernel centered at
p_src = (p + 0.5) * (internal/display) - jitter_px.

If you upsample after TAA without subtracting jitter, you get a 1-pixel box filter forever.
4.2 BATF — bias toward current when variance is already low
text
Copy

R  = max(var_spatial, PITSR_VAR_FLOOR)     // measurement noise
q  = Q_STILL + Q_MOTION * saturate(|mv| / 4.0) + disocclusion*0.2
P- = P_hist + q
K  = clamp(P- / (P- + R), K_MIN, K_MAX)
if (hist_len < 4) K = max(K, 0.5)
if (still && var < VAR_FLOOR*4) K = max(K, K_STILL)  // don't over-smooth clean pixels
μ  = hist + K * (z - hist)

SpectralBlend: after à-trous iteration i (0 = finest):

K_i = K * pow(0.5, i) applied only to the band (this iter residual),
or simpler v1: temporal blend only the coarsest à-trous level; finest level = lerp(cur, filtered, 0.35).

This is the #1 de-blur trick: do not TAA the high frequencies to death.
4.3 AABB must expand with variance

Tight AABB + noisy RT = flicker. Fat AABB + long history = blur.

aabb_expand = (still ? 0.5 : 1.5) * (sqrt(var) + 1e-3) in luma.
Clamp chroma harder than luma (luma carries detail).
4.4 À-trous: edge stop + early out

Weight:

w = w_z * w_n * w_l * w_mat
w_l = exp(-|ΔY| / (SIGMA_LUMA * sqrt(max(var, VAR_FLOOR)) + 1e-4))

    If var < VAR_FLOOR skip remaining iters for that tile (TileClass StableLowVar).
    Performance preset: 1 iter. Balanced: 2.
    Do not increase hole size past 4 on Balanced (1, 2 only).

4.5 Dual history (if you already have it)

Output = lerp(slow, fast, saturate(instability + motion)).
Fast τ ≈ 4 frames, slow τ ≈ 12. Using only slow = blur.
4.6 Sharpen after reconstruct, luma only

CAS (Lottes) on OKLab/Y L, then put chroma back.
sharpness = PITSR_CAS_SHARP (0.85). HDR: sharpen pre-exposed luma, clamp to avoid ringing on fireflies.

If CAS is missing, image will always look like TAA soup.
4.7 StableGrain — why you have “no noise”

Bug: amp = strength * sqrt(var_after_filter) → 0.

Fix: store var_pre before à-trous (tile or pixel). Grain last:
text
Copy

Y = OKLab_L or luma
// mid-grey emphasis (simple)
t = saturate(Y / (Y + 0.18))           // not physically film, looks filmic enough
amp = GRAIN_STRENGTH * mix(GRAIN_MIN, sqrt(max(var_pre, VAR_FLOOR)), 0.65)
amp *= mix(1.0, GRAIN_RESPONSE + t, 0.5)

// blue noise, NOT white, NOT hashed every frame at full strength
n = BlueNoise2D((px, py) + floor(frame * GRAIN_TEMPORAL))   // [-0.5, 0.5], triangular if possible
n = n + BlueNoise2D(...) * 0.5  // 2-tap tri pdf optional

Y' = Y + amp * n

Rules:

    Add grain in luma only, linear/pre-exposed, after CAS.
    GRAIN_TEMPORAL = 0.0–0.2 so still camera is stable grain, not TV static.
    If no blue-noise texture yet: bake a 128² void-and-cluster table as a static const u8[] (do not rand()).
    Never run grain through à-trous.

Optional noise floor (very CoD): even if var_pre is tiny, amp >= GRAIN_STRENGTH * GRAIN_MIN.

Turning/panning the camera makes PiTSR blurry/smeary. Standing still is OK (or better). That means temporal reprojection is wrong under large screen-space motion, not “need more blur.”

CPU-only, raylib/rlgl/rglfw unchanged: no GL on workers.
0. What “blurry when turning” actually is

You are averaging this frame with history that is not the same surface. It looks like motion blur.

Priority order (fix in this order — 1 and 2 are the usual killers in this CPU tiled design):

    History resample is a full-screen gather, not a tile-halo load
    MVs include camera rotation and are in pixels, correct Y sign
    Depth reject + dilated MV on disocclusion
    Trust current when |mv| is large (K up, hist_len down)
    AABB + instability so you don’t keep smeared history

Do not add à-trous iters. Do not raise HIST_LEN_MAX.

2. Bug A (most likely on PiTSR-CPU): halo gather

À-trous halo (8–10 px) is not enough for reprojection. Camera yaw moves pixels tens of pixels. If W2 only reads tile+halo of history, samples clamp inside the tile → smear / trails / tile crawling only when turning.

Rule:

    Spatial (AABB 3×3, à-trous): tile + halo
    History resample: hist[x - mv.x, y - mv.y] from the full history plane (random access, Catmull-Rom 4×4). Any thread may read all of history. Only write the tile interior.

Implementation:

    History buffers = shared SoA, immutable during W2.
    Do not memcpy history into the tile scratch except optional prefetch of a bounding box of the 4×4 taps if you want (bbox = tile expanded by max|mv| in that tile + 2). If max|mv| > 64, skip the copy and gather from the plane.
    Edge: clamp UV to 0.5 .. w-1.5 for Catmull-Rom, and mark those pixels disoccluded (don’t keep stretched border history).

If you used overlapped tiles to “avoid gathers,” revert that for W2 only.
3. Bug B: motion vectors don’t include the camera

raylib scenes often export object velocity = 0. Camera turn then has MV = 0 → TAA stacks unwarped frames → look-smear.

Every pixel:
text
Copy

p  = this-frame clip / NDC / screen
p' = prevViewProj * worldPos     // same world position
mv_px = (p.xy - p'.xy) * 0.5 * internalResolution   // if p in NDC [-1,1]

    Use this-frame depth to reconstruct world pos (view or clip).
    prevViewProj = last frame’s jittered VP if you jittered last frame (match what was actually rendered).
    Y sign: GL NDC Y vs texture Y. One flip is enough to smear. Test: yaw right → background MV must point left in texture space (old pixels come from the right). If opposite, negate mv.x or mv.y.
    Units: pixels in internal res, not display, not UV[0,1] unless every resample agrees. Pick pixels; convert once at ingest.
    Jitter: mv is surface motion only. Do not bake current jitter into MV; jitter is handled in reconstruct. If both are applied, you get extra blur.

If you have no depth: you cannot reproject a 3D camera. Fallback (better than smear):

    Compute a 2D homography from inv(viewProj) * prevViewProj at z = z_focus (camera forward plane) and use that as MV.
    Or: if |camera_rotation| > ε and no depth/MV, resetHistory on the whole frame (sharp, noisy) until G-buffer exists. Smear is worse than a hard cut.

Dilate MV (FSR2-style): 3×3 (or 5×5 on Quality) longest screen motion in the neighborhood (and slightly toward min depth / foreground). Stops edges leaving trails when turning.
4. Bug C: depth reject off → walls smear onto each other

When turning, almost every silhouette is a disocclusion.

Reject history if any:
text
Copy

|z - z_reproj| > τ * z          τ ≈ 0.01–0.03, loosen a bit with |mv|
dot(n, n_hist) < 0.8            if normals exist
reprojected sample out of screen
reactive / alpha

On reject: hist_len = 0, K = K_MAX (~0.85), do not lerp with stale color. Fill from current + short bilateral if you want; never keep the smeared tap.

Reverse-reproject with dilated MV first (FSR2). If still fail, reset.
5. Bug D: Kalman still trusts a long history while |mv| is huge

Even with perfect MVs, 16-frame EMA looks like motion blur.
text
Copy

mv = length(mv_px)
q  = Q_STILL + Q_MOTION * saturate(mv / 4.0)     // Q_MOTION ~ 0.08–0.15
     + 0.25 * disoccluded
K  = clamp(P- / (P- + R), K_MIN, K_MAX)
K  = max(K, saturate(mv / 8.0))                  // turn → trust current
if (mv > 12.0) hist_len = min(hist_len, 4)
if (mv > 25.0) hist_len = min(hist_len, 2)

SpectralBlend: under motion, do not temporally accumulate the finest à-trous band. Finest = mostly current. History only on coarse luma.

AABB: expand with sqrt(var) and |mv|, but luma clamp must still cut trails on high-contrast edges (sky vs gun). If you disabled AABB to “fix flicker,” turn smear comes back — restore AABB, expand it; don’t delete it.

    Do not also DrawTextureEx bilinear the internal RT on top.
    Do not add extra blur “for motion.” PiTSR is not motion blur unless the camera explicitly asks for it.
