DO ADAPTIVE NOW (this is the work)

B1 first — adaptive spp, KEEP 1:1 pixels (no upsample yet)
- Tiles 16×16.
- All pixels get spp_min (batches 1,2,4,…).
- Welford on linear luminance Y = 0.2126R+0.7152G+0.0722B:
    M += (X-M)/n
    S += (X-M_old)*(X-M_new)
    se_rel = sqrt(S/(n-1)) / (sqrt(n)*(M+1e-3))
- Tile contrast C = (Ymax-Ymin)/(Ymax+Ymin+1e-3)
- Keep sampling a tile while n < spp_max AND (se_rel > eps OR C > tau OR geo jump: prim id / |Δn| / |Δz|)
- Compact active tiles each round. Whole tile takes the next batch (no per-pixel warp chaos).
- Stored mean stays unclamped. Variance test may use a luminance clamp/MAD so fireflies don’t eat the budget.
- Output = full-res HDR, variable spp, NO holes, NO upsample.

B2 only after B1 looks right — behind --adaptive-res, DEFAULT OFF
- Coarse 1 ray / 4×4 (or 8×8), quadtree split on contrast/geometry.
- Reconstruct to full output size with joint bilateral (depth+normal+albedo). Never nearest-neighbor.
- Native must not enter this path.

Foveation: default OFF.

Post (don’t put in bounce loop):
- Log-average luminance (downsample OK — this is metering).
- Pupil: D = clamp(4.9 - 3*tanh(0.4*(log10(Lbar)-0.5)), 2, 8)
  exposure *= (D/4)^2 * (0.18/Lbar)
- Bloom: Adaptive may run at 1/4 then add. Native: full res or off.
- Tone map + sRGB last. Denoise HDR optional, default off.

Share with Native: BVH, materials, NEE/MIS, camera, linear workflow.
Fork only: pixel scheduling + (optional) reconstruction.
